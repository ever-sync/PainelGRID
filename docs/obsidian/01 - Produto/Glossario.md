# Glossário

| Termo | Definição |
|---|---|
| Lead | Pessoa captada, importada ou criada manualmente e vinculada a um cliente |
| Evento de interesse | Evento ao qual o lead está associado |
| Pipeline | Funil de CRM de um cliente |
| Etapa | Coluna do pipeline |
| Agendamento | Registro operacional com data, origem, canal e status |
| Credenciamento | Coleta e confirmação dos dados necessários para participação |
| Rubinho | Agente de atendimento e credenciamento no WhatsApp |
| Dispatch | Tentativa rastreada de comunicação por template, e-mail ou automação |
| WABA | Conta do WhatsApp Business |
| Phone Number ID | Identificador Meta do número que recebeu ou enviou a mensagem |
| Leadgen ID | Identificador de uma resposta de formulário Meta |
| Handoff | Transferência da conversa para atendimento humano |
| Check-in | Confirmação de chegada ao evento |
| No-show | Agendado que não compareceu |
| FIPE | Referência de veículo consultada a partir da placa |
| Idempotência | Garantia de que repetir uma operação não cria duplicidade |
